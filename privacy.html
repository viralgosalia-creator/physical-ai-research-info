Privacy notice

This application is operated by Viral Gosalia for a private research project.

Google data and permissions

The proposed Drive connection requests permission to access Google Drive. With the full Drive permission, Google grants account-wide Drive access; the configured upload script restricts its operations to the designated project folder. That script lists destination file metadata and hashes, uploads generated research files and code snapshots, and verifies uploads. It does not intentionally collect unrelated Drive documents.

Storage and sharing

Research archives and code are stored in a private GitHub repository and copied to the designated shared Drive folder. The configured research recipients receive newsletters by email. GitHub Actions processes the files and Google hosts the Drive copies. Access follows the project owner's repository and folder permissions.

OAuth credentials are stored as a GitHub Actions secret and in a private local setup file. The workflow creates a temporary credential file on its runner and removes it after use. Upload logs may contain file names and transfer results.

Use and retention

Google user data is used to operate the requested publishing connection, not to sell data or train generalized AI models. Copies remain in GitHub and Drive until the owner removes them; deleting a copy in one service does not delete the other. Google Drive sharing and retention are controlled by the owner.

Control and contact

The owner can revoke the Google connection in Google Account third-party access settings and remove the DRIVE_CONFIG GitHub secret to disable cloud publishing. Contact viralgosalia@gmail.com for questions or removal requests.

This notice must be reviewed and updated if permissions, providers or data practices change.
